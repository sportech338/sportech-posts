# Sportech Posts

Artes e automação do Instagram **@sportech** para o produto **CoolerBag**.

- `INSTRUCOES.md`: a rotina diária e a semanal que as tarefas automáticas seguem.
- `produto/coolerbag.md`: preços, informações e regras do que pode ou não ser dito.
- `fotos/`: fotos do produto já recortadas, com descrição em `fotos.json`.
- `gerador/render.py`: gera as artes a partir de um plano JSON.
- `planos/`: o plano de cada dia, com textos, layouts e legendas.
- `posts/`: as artes publicadas. É daqui que o Metricool pega as imagens.
- `historico.json` e `aprendizados.md`: memória do que foi postado e dos ajustes feitos a partir das métricas.
